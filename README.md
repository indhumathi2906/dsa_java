## 🛠 Quick Start Guide

### Compile and Run Master Suite
```bash
# Clone the repository
git clone https://github.com/indhumathi2906/dsa_java.git
cd dsa_java

# Compile master solutions
javac Arrays_Master_Solutions.java

# Execute test suite
java Arrays_Master_Solutions
```

### Compile Individual Problem Files
```bash
# Example for Problem 1
javac Array_P1_TwoSum/Array_P1_TwoSum.java
java Array_P1_TwoSum.Array_P1_TwoSum
```
